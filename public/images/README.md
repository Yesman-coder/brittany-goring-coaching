# Photos go here

Drop Brittany's real photos into this folder using these **exact file names**.
The site picks them up automatically — no code changes needed. Until a file
exists, the site shows a tasteful placeholder in its place (no broken images).

| File name               | Where it appears        | Suggested size / ratio      |
| ----------------------- | ----------------------- | --------------------------- |
| `brittany-portrait.jpg` | Hero (main portrait)    | Portrait, ~1000×1250 (4:5)  |
| `about-1.jpg`           | About section (left)    | Portrait, ~800×1066 (3:4)   |
| `about-2.jpg`           | About section (right)   | Portrait, ~800×1066 (3:4)   |
| `team-1.jpg`            | Team gallery            | Portrait, ~800×1066 (3:4)   |
| `team-2.jpg`            | Team gallery            | Portrait, ~800×1066 (3:4)   |
| `team-3.jpg`            | Team gallery            | Portrait, ~800×1066 (3:4)   |
| `team-4.jpg`            | Team gallery            | Portrait, ~800×1066 (3:4)   |

Tips
- `.jpg`, `.png`, and `.webp` all work — keep the file name (change the code in
  `src/config/site.ts` only if you want a different extension).
- Compress images before adding them (try https://squoosh.app) so the site stays fast.
- Captions and alt text for the team photos live in `src/config/site.ts`.
